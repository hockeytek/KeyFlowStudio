# Code of Conduct

This project follows a simple standard: be respectful, constructive, and specific.

## Expected Behavior

- Use welcoming and inclusive language.
- Focus feedback on code, behavior, and outcomes.
- Assume good intent while still being precise about risks.
- Respect privacy and confidentiality.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private credentials, footage, or infrastructure details.
- Disruptive or bad-faith participation.

## Enforcement

The repository owner may remove comments, close issues, restrict access, or block contributors who violate this code of conduct.
