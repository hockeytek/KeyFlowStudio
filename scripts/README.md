# Scripts

This directory contains development helpers for KeyFlow Studio.

Active helpers:

- [p1_regression.py](p1_regression.py) - quick P1 regression checks, usually run through [run_p1.sh](../run_p1.sh).
- [install_sam2_intel_workaround.sh](install_sam2_intel_workaround.sh) - Intel macOS SAM2 install workaround.

Historical one-off tools live in [archive/](archive/).
